# Commercial Evaluation Path

Chimera Adaptive Architecture is available for controlled technical evaluation by qualified organizations.

## Evaluation sequence

1. **Fit review** — establish the buyer's technical problem, intended environment, evaluation objective, and authorized reviewers.
2. **Commercial terms** — execute an NDA where appropriate and agree to an evaluation/audit license defining scope, duration, permitted use, confidentiality, access controls, and fees.
3. **Payment / entitlement** — evaluation access is provisioned only after the applicable commercial gate is satisfied.
4. **Controlled technical access** — approved reviewers receive only the materials required for the agreed evaluation. Access to private source or documentation is limited by the executed terms.
5. **Evidence review** — evaluate architecture behavior, interfaces, controls, traceability, and agreed success criteria without requiring public disclosure of the private substrate.
6. **Commercial decision** — conclude the evaluation, extend it, convert to a production/OEM/license arrangement, or terminate access according to the applicable agreement.

## Evaluation boundaries

A commercial evaluation does not automatically grant production rights, sublicensing rights, redistribution rights, source-code ownership, or rights to create derivative commercial products. Those rights, if any, require a separate executed agreement.

The specific scope, fee, duration, access method, success criteria, and conversion credit are negotiated for the evaluation at hand rather than published as a public price list.
